# FORMULA 1 — INSIDE THE MACHINE

Интерактивный сайт на основе **Formula1_Engineering.blend / VANTA R26**. Исправленная веб-модель R2 содержит 1 267 деталей и 35 сборок. Изменены геометрия банков цилиндров, корпус КПП, улитки турбоагрегата и размещение маслобака. Исходный `.blend` сохранён; редактируемая версия записана отдельно в `artifacts/Formula1_Engineering_Web_R2.blend`.

## Запуск

Нужен Node.js 22.12+ (проверено на 24.18) и npm.

```sh
npm install
npm run dev
```

Локальный адрес: http://localhost:5178. Производственная сборка:

```sh
npm run build
npm run preview
```

## Как исследовать

- «Исследовать двигатель»: десять глав на двенадцати высотах экрана; 19 опорных ракурсов с паузами на крупных планах. Вертикальная шкала позволяет перейти к главе. При прокрутке назад геометрия возвращается.
- «3D-лаборатория»: вращение левой кнопкой, панорамирование правой, приближение колёсиком. На телефоне используются касания и жест двумя пальцами.
- Клик по детали открывает описание и фокусирует камеру. Поиск принимает русский/английский термин или ID, например `INT-0007`.
- Слайдер последовательно освобождает внешние узлы, открывает головки, извлекает поршни по осям цилиндров и опускает коленвал. Дополнительные слайдеры выбирают этап; соседние узлы автоматически освобождают проход. Кнопка восстановления сбрасывает ручные настройки.
- Фильтры систем, подписи, скрытие корпусов, рентген, изоляция, потоки, полный экран и режим презентации действуют на реальную 3D-сцену.
- «Рабочий цикл» показывает замедленное движение шести поршней, шатунов и сборки коленвала. Это учебная кинематика из размеров модели, не физическая симуляция работающего двигателя. Газораспределение в этом режиме неподвижно.
- Ссылка из инспектора сохраняет ID, степень общей разборки и положение камеры.

## Повторный экспорт вашего Blender-проекта

В комплекте уже есть готовый `public/models/engine.glb`. Интернет для загрузки модели и шрифтов во время просмотра не нужен.

Из этой папки в PowerShell, если исходный проект расположен рядом:

```powershell
& '..\FORMULA_1_ENGINEERING_PROJECT\tools\blender-4.5.9-windows-x64\blender.exe' --background '..\FORMULA_1_ENGINEERING_PROJECT\Formula1_Engineering.blend' --python-exit-code 1 --python '.\scripts\blender_export\export_engine.py' -- --output '.\public'
npm run optimize:model
npm run validate:model
npm run build
```

Можно заменить путь к Blender и `.blend` абсолютными путями. Контракт метаданных и сцены описан в [docs/model-integration.md](docs/model-integration.md). Экспортёр предназначен для поставленного проекта VANTA R26; другой проект требует сопоставления его систем и групп.

## Структура

- `src/scenes/EngineScene.tsx` — WebGL, студийное HDR-окружение, камера, потоки.
- `src/components/engine/` — загрузка, исходные трансформации, разборка, выбор, кинематика, подписи, лаборатория.
- `src/stores/engineStore.ts` — единый Zustand store для истории и лаборатории.
- `src/data/` — главы и 13 учебных тем.
- `public/models/` — сжатый GLB и каталог из Blender extras. Несжатый экспорт и отдельный исправленный `.blend` находятся в `artifacts/`.
- `public/documentation/` — реальные Markdown-файлы исходного проекта.
- `scripts/` — Blender-экспорт, сжатие, проверки и браузерный аудит.
- `docs/` — архитектура, интеграция, производительность, ограничения.

## Ограничения и происхождение

Проект независимый, образовательный и не связан с конкретной командой F1. Исходная модель — авторская реконструкция. Микротекстуры Blender в GLB упрощены до PBR-параметров; динамический поток обозначает функциональный маршрут, а не CFD. Подробности: [технические ограничения исходника](public/documentation/TECHNICAL_LIMITATIONS.md) и [архитектура](docs/architecture.md).

Изменения геометрии, назначение новых траекторий и точный объём проверки пересечений: [docs/revision-r2.md](docs/revision-r2.md).

Учитывается `prefers-reduced-motion`; автоматическое движение камеры отключается. При отсутствии WebGL 2 доступен исходный Blender-рендер и текстовые разделы. Экономичное качество уменьшает DPR и скрывает мелкий крепёж, сохраняя выбранную деталь. Частота кадров зависит от GPU; 60 FPS не гарантируются.
