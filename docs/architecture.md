# Архитектура

React 19, TypeScript, Vite 8, Tailwind 4, Three.js r186, React Three Fiber 9, Drei 10, GSAP 3 и Zustand 5. Используется один Canvas и один набор геометрии. Интерфейс не создаёт вторую копию 3D-модели при переходе из истории в лабораторию.

`ModelLoader` загружает локальный manifest и GLB через GLTFLoader с MeshoptDecoder. Проценты отражают загруженные байты GLB при доступном Content-Length; последняя стадия включает декодирование и проверку количества ID. До подготовки критических ресурсов виден экран загрузки. Ошибки имеют возможность повтора.

`ScrollExperience` создаёт GSAP ScrollTrigger с pin и scrub. Нормализованный progress хранится в Zustand. `assemblyTimeline.ts` задаёт единую последовательность разборки, а `manifest.trajectories` — интервалы 35 сборок. `ExplodedViewController` пересчитывает положение от неизменяемой исходной позиции; трансформации не накапливаются. Смещение в мировых осях переводится в локальную систему родителя через обратную матрицу, включая его масштаб.

`CameraController` использует 19 подготовленных ракурсов, остановки и сглаживание пятой степени. В лаборатории OrbitControls получает управление после завершения перехода. При выборе детали камера ориентируется на фактический центр её геометрии. В главе разнесённого вида доступно ручное вращение. Один `mode` предотвращает конфликт ручного управления и scroll timeline.

`PartSelectionController` связывает meshes с записями manifest. Точное повторение геометрии и материала в одной группе объединяется через InstancedMesh; instanceId возвращает исходный part_id. Движущаяся поршневая группа и коленвал исключены из такой пакетной обработки. Материалы обычных частей клонированы, чтобы выбор одной детали не перекрашивал соседние.

`WorkingCycleController` вычисляет положение поршневого пальца из длины шатуна и положения кривошипа. Реальные mesh-объекты перемещаются как твёрдые тела. Точка большой головки следует кривошипу, малая — оси цилиндра, стержень шатуна получает согласованный поворот. Кривошипы вращаются вокруг исходной оси коленвала. Возврат из режима восстанавливает матрицы. Клапанные фазы, горение, трение и деформация не моделируются.

Каталог строится только из экспортированных деталей, имеет поиск, фильтр и пагинацию по 12. Кнопки выбора переводят в лабораторию. Энциклопедия пересказывает документацию проекта и общие принципы; под ней доступны оригинальные Markdown-файлы через marked с отключённым сырым HTML. Внешние официальные источники приводятся для архитектуры и ограничений мощности 2026.

URL hash хранит режим, выбранную деталь, assembly, camera и target. Серверная база, учётные записи или внешние API для работы опыта не нужны. Сайт может публиковаться как статический dist. Оригинальный Blender-проект не включён в сайт и остаётся рядом в рабочей директории.
