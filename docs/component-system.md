# Компоненты и управление

Каталог включает только 1 267 узлов настоящего GLB. Один ID соответствует одному объекту-носителю метаданных. Многоматериальные дочерние meshes относятся к ближайшему предку с part_id. Для InstancedMesh массив partIds сопоставляет каждый экземпляр исходной детали.

В интерфейсе технические системы сгруппированы в десять фильтров: блок/головки, поршневая, газораспределение, наддув, гибрид, топливо, охлаждение, смазка, электрика и трансмиссия. Разделение смазки и охлаждения производится по названиям компонентов системы 12. Оригинальное поле system сохраняется без изменений.

Фокус, подсветка, изоляция, скрытие корпуса и рентген независимы от базовых трансформаций. При выборе внутренних деталей оболочки становятся прозрачнее. Отключённая система не удаляет геометрию и не теряет метаданные. В экономичном качестве выбранная мелкая деталь снова становится видимой.

Слайдер assembly управляет общей последовательностью. Слайдеры этапов автоматически освобождают предшествующие узлы. Движение обратно восстанавливает точную исходную позицию. «Восстановить исходный вид» очищает отдельные слайдеры, выбор, фильтры, эффекты и положение камеры.

Подписи используют реальные IDs и следуют объектам после разборки. Чтобы не закрывать модель, без выбора показывается небольшой набор опорных компонентов; при выборе — только выбранная деталь. Режим презентации скрывает интерфейс, оставляя вращение модели и кнопку выхода.
