# Выполненные проверки

Дата: 9 октября 2026. Локальная среда Windows, Node.js 24.18, Blender 4.5.9 LTS, Chromium / Microsoft Edge в headless-режиме.

## Экспорт и геометрия

`npm run validate:model`: 16 проверок. 1 266 уникальных IDs, 18 сборочных групп, геометрия и нормали у каждой детали, конечные координаты, корректные индексы треугольников. Подтверждены 6 поршней, 6 шатунов, 6 шатунных шеек, 4 распредвала, 24 клапана, 6 форсунок, MGU-K и вал турбокомпрессора. MGU-H отсутствует. SHA-256 исходного `.blend` не изменился.

## Логика

`npm test`: 4 теста. Проверены локальные траектории при повёрнутом и масштабированном родителе; отсутствие накопления ошибки после 200 циклов; детерминированность скролла и точная сборка на progress=1; длина шатуна 112 мм на 720° в обоих банках; сопоставление instanceId и исходного ID крепежа.

## Браузер

`node scripts/browser-qa.mjs`: 26 проверок. Проверялись:

- Реальная загрузка 1 266 узлов GLB и instancing повторяющихся деталей.
- Переход по главам, изменение координат от прокрутки, полная разборка и обратная сборка.
- Вращение мышью, raycast-выбор детали на поверхности модели, фильтрация систем.
- Слайдер разборки в обе стороны, поиск по ID, инспектор, изоляция, подписи и рентген.
- Запуск учебного рабочего цикла.
- Поиск по каталогу и пустая выдача; переключение потока энергии на схеме рекуперации.
- Мобильное меню и доступность фильтров систем; отсутствие горизонтального переполнения.
- Неподвижная начальная камера при prefers-reduced-motion.
- Исходный Blender-рендер при отключённом WebGL 2 и отсутствие неработающего интерфейса лаборатории в этом режиме.

Основные размеры: desktop 1440×1000, mobile 390×844; reduced-motion 1280×900. Критических ошибок консоли и исключений JavaScript в проверенном маршруте не обнаружено. Снимки сохранены в `artifacts/` и просмотрены при визуальной проверке.

## Сборка и пределы проверки

Производственная сборка выполняется `npm run build` (TypeScript + Vite). `npm install` завершился без выявленных npm audit уязвимостей на момент установки. Вспомогательные Sites-скрипты установки/сборки столкнулись с ошибкой разрешения npm в Windows; использован штатный `npm.cmd`, без изменения файлов плагина.

Не выполнялись: проверка на физических iOS/Android устройствах, Safari/Firefox, полный аудит WCAG, сертифицированный замер FPS на разных GPU, CFD/FEA или проверка заводских допусков. Отчёт не утверждает, что эти проверки пройдены. Опубликованная версия проверяется по успешному статусу развёртывания; агент не выполняет дополнительный вход в приватную production-страницу.

Машиночитаемые отчёты: `artifacts/browser-qa.json` и `artifacts/model-validation.json`. Их копии сохранены рядом с этим документом для независимого чтения.
